# 中文界面与响应式验证 — 2026-10-30

## 范围

本次检查包括本地独立 Chromium 预览页面和用户在已重新加载的本地 Codex 插件中的交互确认。Chromium 使用合成示例数据，不连接 Codex 会话；Codex 桌面端的语言结果由用户确认，不是自动化截图验证。两者均不验证宿主事件采集或真实 Token 用量。

## 结果

- 默认语言为简体中文，文档根节点设置为 `lang="zh-CN"`；右上角按钮可切换英文并更新为 `lang="en"`，再次切换可回到中文。
- 会话入口、状态、事件标签、统计标签、按钮、空状态、可访问性标签及合成数据说明均使用对应语言。技术协议标识与产品/代码专名保留原文。
- 在 360、420、720、800px 视口逐一检查，`document.documentElement.scrollWidth` 与视口宽度一致，没有横向溢出。
- 浏览器截图保存在本目录的 `ui-i18n-360-zh.png`，展示 360px 下的中文合成预览。
- 测试另有静态渲染检查：默认中文、英文模式、合成状态本地化；MCP 工具元数据及用户可见响应也验证为中文。
- 用户在 Codex 新聊天重新加载插件并打开 `open_session` 后确认：面板默认中文，EN 按钮能切换到英文。该项记为用户确认的宿主实测。

## 验收边界

截图来自 standalone synthetic preview，不是 Codex MCP Apps 宿主界面。中文默认显示和英文切换已在用户本地 Codex 新聊天中确认；自动化工具无法读取该聊天的宿主面板，因此没有独立截图证据。宿主事件采集与真实 Token 用量仍待验证。
